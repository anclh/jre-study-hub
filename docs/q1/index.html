Q1 Discussion Paper / Memo：精簡版

Sort → Analyse → Compare → Recommend
分類 → 證據推影響 → 比較取捨 → 提出可執行方案

  1. 1. Sort the Data File｜頭 5 分鐘
    • Role / Audience / Task — 我係邊個？寫畀邊個？要對方決定咩？
    • P1 / P2 — 兩個問題，各圈最有用嘅數字。
    • Options — 各方案嘅好處、成本同需時。
    • Objections / Constraints — 邊個有咩疑慮？有咩預算、人手或時間限制？
    • Delivery — 掃一眼可用嘅試點、配套同指標，略過無關資料。
  2. 2. Identify Problems & Implications｜一個問題一段
    • Problem → Evidence → Interpretation → Implication
    • 問題 → 證據 → 缺口 → 後果。每段問自己：數字反映咩？邊個受影響？點解值得政府介入？
    • P1、P2 各講一個缺口。影響可以落喺服務使用者、公帑或整個制度。
  3. 3. Compare Options｜同一套準則
    • Criteria — 有指定準則就逐項答。否則揀最影響決定嘅兩三項，如成效、成本、人手／時間、服務可及性。
    • Trade-off — 每個方案寫清楚：有咩好處？最大限制係咩？呢個限制點樣影響選擇？
    • Choice + objection — 講明點解揀首選，再喺相關方案段內交代點樣回應疑慮。
    • Budget check — 一次性同年度經常開支分開。用組合方案，就加總同一期間嘅已知成本，再對照財政條件。
  4. 4. Recommend & Close｜由方案寫到落地
    • Who / When / Where — 邊個牽頭？邊個協作？幾時喺邊度試行？
    • Resources / Support — 要幾多錢同人手？核心措施同配套各處理邊個缺口？
    • KPIs / Review — 睇咩指標？幾時檢討？咩結果先支持擴展？
    • Approval — 一句講清楚而家要批咩。Members are invited to endorse [specific proposal].

先查邏輯，再查結構同執行。 首選要由證據同方案比較推得出。如果保留之前指出有風險嘅設計，就交代具體配套，或者解釋點解剩餘風險可接受。
Check logic first, then structure and delivery. The recommendation should follow from the evidence and comparison. If it retains a feature you criticised, specify the safeguard or explain why the remaining risk is acceptable.

考場提自己／Exam cue
先用短語同數字列骨架。落筆時，每個數字都要幫你解釋問題、比較方案，或者支持建議。
Plan in notes. Use each figure to explain a problem, weigh an option or justify a recommendation.

Answer frame

5 部分 · 約 700 字 · 55 min

按上面四步用約 15 分鐘規劃，頭 5 分鐘分類 Data File。寫作時開首先講建議，執行段直接點名負責部門，證據同成本寫到資料支持嘅程度。

  1. 1. Opening（約 50 字 · 3 min）

    交代爭議成因、擬議措施同文件範圍。約 50 字為預設，背景較複雜時可用 5–7 個短句。數字能夠量度問題，就用數字開首。數字只顯示活動量或趨勢，就寫清楚有咩需要檢視。
    State the root of the dispute, the proposed action and the scope of the paper. Aim for about 50 words. Use five to seven short sentences if the context warrants it.

    • 問題＋建議　[Key figure or case fact] highlights [specific problem or issue that warrants review]. This paper examines two barriers to [objective], compares the available options and recommends [specific action], subject to [key condition, if applicable].
  2. 2. Problem analysis（兩段共約 210 字 · 15 min）

    每段一個缺口。按 Problem → Evidence → Interpretation → Implication 寫，講清楚邊個會受影響、點樣受影響。

    • P1　A key barrier to [objective] is [specific gap]. Document [X] shows that [evidence]. This suggests that [what the evidence indicates]. If the gap persists, [affected group] may [specific consequence].
    • P2　A further concern is [distinct gap]. [Evidence from Document Y] points to [what needs attention]. If [mechanism or condition], [affected group or service] could [specific consequence].

    While… 留畀有實質反差嘅數據。資料只支持「值得檢視」時，可以用 “These figures warrant a check on whether…”。

  3. 3. Option comparison（約 210 字 · 18 min）

    用同一套準則比較每個方案嘅好處同決定性限制。題目有指定準則就逐項答。首選段講明點解最適合，再用一項具體措施回應主要疑慮。

    • 比較準則　The immediate priority is to [desired outcome]. The options are assessed on [two or three criteria].
    • 逐個方案比較　[Option] would [specific benefit]. Its [cost, lead time or delivery requirement] would [consequence for the decision].
    • 首選＋回應疑慮　On balance, [preferred option] offers the strongest prospect of [outcome] because [case-specific reason]. To address [stakeholder]’s concern about [risk], [responsible party] should [specific safeguard].
    • 成本未明　Implementation should be subject to a costed plan and approval.

    有成本資料時，分開一次性同年度經常開支。組合方案要加總同一期間嘅已知成本，再對照適用嘅財政條件。

  4. 4. Recommendation（約 170 字 · 15 min）

    直接由部門做主語。交代邊個牽頭、合作方做咩、幾時同喺邊度試行，以及需要咩資源。核心措施同配套要各自對應 P1、P2。

    • 主責＋試點＋措施　[Lead bureau] should pilot [preferred option] in [location or service setting] within [timeframe], with [partner] responsible for [specific task]. The pilot should [core measure addressing P1]. [Responsible team] should also [complementary measure addressing P2]. Before launch, the Bureau should confirm [funding, staffing or delivery capacity].
  5. 5. Closing（約 60 字 · 4 min）

    按 Review → Decision → Approval 寫。交代幾時檢討、睇咩結果先擴展，同埋而家要批咩。基線未有，就先收集基線，再訂數值目標。

    • 檢討＋決定＋呈批　At the [time] review, the Bureau should assess [outcome], [service or quality measure] and [cost] against [baseline or agreed targets]. It should expand the scheme only if [specific conditions are met]. Members are invited to endorse [specific action or approval sought].

考場速記／Exam cue
講決定 → 用證據推後果 → 比較取捨 → 點名落實 → 檢討呈批。
State the decision → Explain the implications → Weigh the options → Assign delivery → Set the review and seek approval.

可讀性／Readability
概述 Data File，每段集中一個論點。英文段落最多 150 字，每節約 500 字為練習上限。沿用題目城市名稱，並以部門、委員會或文件作主語。
Summarise the Data File and give each paragraph one main point. As practice ceilings, keep paragraphs to 150 words and sections to about 500. Use the city named in the task and write without first person.

文筆一般都夠

考試靠骨架，唔靠文采。每段套住 Data File 數字用；下面各 stage 有更多句式。

  1. The key concern is… 核心問題係…
  2. This risks exacerbating / undermining… 恐會加劇／削弱…
  3. There could be knock-on effects on… 或會對…產生連鎖影響
  4. As indicated in Document X… 據文件 X…（一句，唔抄長段）
  5. On balance, Option A is preferable because… 權衡後較宜選 A，因為…
  6. This directly addresses the concern that… 此舉直接回應…嘅疑慮
  7. It is recommended that [dept] … within [timeframe], subject to… 建議由…於…內推行，惟須…
  8. A sequenced / pilot approach would… 分階段／試點有助…
  9. Success should be reviewed against [2 to 3 KPIs]… 宜以…檢討成效
  10. Residual risk remains… and should be monitored. 殘餘風險為…，須持續監察

1. Opening（約 50 字）

爭議成因＋擬議措施＋文件範圍。用一項關鍵證據交代背景。
Starters：The main challenge is… / The key issue facing the administration is…

Shared frames

  • ［具體問題］令［群體］面對［後果］。本文檢視可行方案，並建議先採取［針對性措施］。 / [Specific problem] exposes [group] to [consequence]. This paper assesses the options and recommends [targeted action] as an initial step.

句式

opening

2. Problem analysis（2 個）

每個：是什麼 + implications（用 Data File 證據）。典型 implications：fiscal／manpower／service quality／public confidence／knock-on effects。Analyse，唔 paraphrase。
Starters：This may give rise to… / There could be knock-on effects on… / Left unaddressed, the problem risks…

Shared frames

  • 有助……惟須…… / This helps to… but must be accompanied by…
  • 短期……惟長遠…… / In the short term… but in the long term…
  • 在長遠方案出台前，需有過渡措施。 / A stopgap measure is needed pending a longer-term solution.

句式

implications, assessment

3. Option comparison（2 至 3，得分核心）

固定 criteria：effectiveness｜cost／resources｜feasibility｜stakeholder impact／acceptance。主動回每 option 嘅最強 objection。
Starters：Option A scores higher on feasibility but lower on cost-effectiveness. / After weighing the trade-offs…

Shared frames

  • 權衡利弊後…… / After weighing the pros and cons…
  • 權衡取捨後，宜採用混合方案…… / After weighing the trade-offs, a mix of … is preferred.
  • ［持份者］關注［新增負擔］。［具體調整］可減輕負擔，並維持對［政策目標］嘅保障。 / [Stakeholder] is concerned about [added burden]. [Specific adjustment] would reduce that burden while protecting [policy objective].
  • 若不採納原建議，仍宜以……作為替代，繼續推進……目標。 / If the original proposal is not adopted, … remains a workable alternative to advance….

句式

comparison, balance

4. Recommendation

清晰選項（one 或 mix）。必須：who leads、pilot／phased、KPIs、timeline、resource condition。效果用 may／could／if accompanied by…。
Starters：It is recommended that a pilot be launched in… / The [Bureau] should lead… / Subject to available resources…

Shared frames

  • 建議先推行試點…… / It is recommended that a pilot be launched…
  • 視乎可用資源…… / Subject to available resources…
  • 應由〔政策局／部門〕主導，並由……支援。 / The [bureau/department] should lead, with support from….
  • 應設定指標以量度成效。 / KPIs should be set to measure effectiveness.
  • 可視乎檢討結果考慮擴大推行。 / Consideration may be given to scaling up subject to review findings.

句式

recommend, specificity, monitor

5. Closing（短）

Residual risks + 如何 monitor／review。
Starters：Residual risks remain and should be monitored. / A review should be conducted after 12 to 18 months.

Shared frames

  • 仍有剩餘風險，應持續監察。 / Residual risks remain and should be monitored.
  • 建議委員批准［即時行動］，並於［時間］按［成效指標］檢討。 / Members are invited to endorse [immediate action] and review [outcome indicator] after [period].

句式

discourse，其他

  • 加配套或收窄漏洞　視乎問題，可以加入核查、申訴或資格準則，亦可以限制會引致濫用嘅做法。
    Add a safeguard or curb the source of abuse. Consider checks, appeals, eligibility criteria or a limit on the practice causing the abuse.
  • 比較介入程度　規管可由指引、與投標評分掛鈎嘅自願約章或認可名單，去到合約指標、發牌、法定罰則或禁令。支援可考慮培訓資助、財政誘因、整合資源、簡化服務、跨境合作、豁免或限制外部競爭。以證據講明點解需要較強措施，並核對所需權限。
    Compare levels of intervention. Regulatory tools range from guidance, voluntary charters linked to tender scoring and approved lists to contract KPIs, licensing, statutory penalties and bans. Facilitation options include training subsidies, financial incentives, pooled resources, streamlined services, cross-boundary cooperation, exemptions and limits on outside competition. Justify stronger intervention with evidence and confirm the necessary powers.
  • 講清楚科技點樣發揮作用　樽頸 → 工具嘅具體功能 → 功能點樣改善流程同預期效果。
    Explain how the technology helps. If applicants abandon a long form, a save-and-resume feature lets them finish later. Track completion rates to test the effect.
  • 回應承受成本嘅一方　可調整推行細節、配合既有或已規劃支援，或者用證據交代間接得益、延誤嘅代價或更重要嘅公共利益。
    Respond to the group bearing the cost. Adjust the design, pair it with existing or planned support, or make an evidence-based case for indirect benefits, the cost of delay or a higher-priority public interest.

交卷前　如果措施已經實施，寫明要補邊個缺口。如果主要方案已做到同一效果，就刪去重複配套。核對介入程度同問題規模。
Before submitting. If the measure already exists, specify the gap the proposal would close. Drop safeguards that duplicate the main policy’s effect. Check that the intervention is proportionate and the problem fits the paper’s scope.

7. 問題與配套對照
7. Matching problems with measures

  • 用唔到服務 → 延長時間、交通支援、人工／紙本渠道。
    Barriers to access → Extend opening hours, offer transport support and provide staff-assisted or paper-based options.
  • 申請慢 → 刪重複資料、保存進度、指定跟進人員。
    Slow applications → Remove duplicate requests for information, let users save their progress and assign someone to follow up.
  • 質素／安全不足 → 獨立覆核、分段驗收、風險通報。
    Quality or safety gaps → Arrange independent review, carry out staged acceptance checks and report risks.
  • 利益衝突 → 申報、避席、獨立評分、公開理由。
    Conflicts of interest → Require declarations and recusal, arrange independent scoring and publish the reasons for decisions.
  • 成效不明 → 建立基線、追蹤實際結果、適當比較。
    Uncertain effectiveness → Establish a baseline, track outcomes and choose a suitable comparison.
  • 供應不足 → 購買有質素服務、調配人手、評估長遠擴建。
    Insufficient supply → Purchase services that meet quality standards, redeploy staff and assess longer-term expansion.

8. 考場速記
8. Exam reminders

  • 問題　不足、錯配、門檻、跟進／監管不足、成效證據不足。
    Problems — Shortages, mismatches, access barriers, weak follow-up or oversight, and limited evidence of results.
  • 影響　延誤、不平等、家庭負擔、服務壓力、公帑效益及安全風險。
    Impacts — Delays, inequality, strain on families and services, value for public money, and safety risks.
  • 方案　解決到幾多、幾快做到、成本幾多、邊個用得到、有咩風險。
    Options — How much will each option achieve, how soon and at what cost? Who can use it and what are the risks?
  • 建議　邊個做、先做邊度、幾時開始、幾多資源、咩配套、點驗證成果。
    Recommendation — Who leads, where and when does it start, what resources and safeguards are needed, and how will results be checked?
