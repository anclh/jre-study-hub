英文 Q1

Discussion paper · Data File · phrase bank

1. 角色與時間

  • 型式＝internal discussion paper / memo（虛構近香港城市，常見 City of Jade）。
  • Data File＝答題物料，唔係「讀完再寫作文」。
  • 官方大致兩塊：① two major problems + implications；② feasible measures（全文 English）。
  • 時間（非官方）：全卷 3h 兩卷；Q1 常用 ~20′ 大綱／Data File + ~70′ 寫。紙上 checkpoint 例：15′ DF 完｜40′ 寫到 recommendation｜55′ 收尾。留時間畀中文卷。

2. 答題框架

分析問題 → 影響 → 可行措施（who / when / resources）。

  1. Opening（1–2 句） 問題 + 政府目標（criteria）。越短越好——唔堆背景／多個實數；分數唔喺公文 Purpose 格式。
  2. Problem analysis 2 個問題 + implications（users / fiscal / social）。證據來自 Data File：analyse，唔 paraphrase。每條：現象 → 邊啲人／錢／社會 → 點解 urgent。
  3. Option comparison（得分核心） 2–3 options，同一套 criteria：effectiveness · cost · stakeholders · feasibility／risk。主動回 Data File objections。
  4. Recommendation 揀 one／mix；phased／pilot／KPIs。清晰推薦（唔「利弊各半」）；效果用 may／could／if accompanied by…。
  5. Optional close Residual risks／follow-up（短）。

3. Data File 與開卷

Data File＝輔助，唔係答案本。唔背、唔大篇抄；主體係你嘅分析。

  1. Scratch（2–3 min）：題目要求一句 → 3–5 quotable（標 A–G）→ 旁標 P1／P2／Rec／Obj → Outline → Criteria 四格。只寫 keywords。
  2. 流程：先大綱（問題＋每段用途）→ 定向翻查 → 整合。訪談＝stakeholder；數字＝一句＋implies／points to…。每段最多 1 個引用。
  3. Timed drill（15–20 min）：3–5′ sort（support／oppose／neutral／risk）→ 3–5′ highlight → drop 用唔到嘅 → outline only。
  • 全卷 DF 理想 < ~15 min；唔好逐份 document 由頭讀到尾。
  • Never copy 長段 background（paraphrase of background scores nothing）。
  • 冷門題：DF 就係全部背景——唔使背史；跟 criteria 拆；結構仍跟本頁框架。

4. 寫作：精簡 · 語氣 · 字數

  • 精簡：每句有功能（問題／implication／比較／objection／recommend）。數字只揀撐論點嘅；引完一句 implies。唔為填頁灌水。
  • 字數：官方無硬性字數——質＞量。坊間「幾頁／幾多字」唔當指標。
  • 時事：DF 優先；外加只借措施樣板（who／pilot／「有助…但須…」）——唔堆新聞入 Opening。
  • 語氣：角色＝內部官員（建議、分析），唔係評論員。中立＋事實；weighing／hedge；部門＋KPI。
  • 避免：I think、絕對化、「政府明顯失敗」；少用 Unlike／Better than 暗示舊政策做錯；建議唔好只講「加強宣傳」。
