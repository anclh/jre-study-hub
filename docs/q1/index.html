Answer frame（內部討論文件）

Data File 係物料，唔係作文。分析問題 → 影響 → 可行措施（who / when / resources）。

  1. 1. Opening一句問題 + 政府目標／criteria
  2. 2. Problems + implications兩大問題；每條：現象 → 影響（users / fiscal / social）
  3. 3. Option comparison2–3 options，同一套 criteria；回應 Data File objections
  4. 4. Recommendation揀一個／組合；phased / pilot / KPI
  5. 5. Optional closeresidual risks／跟進（短）

Timed Data File tip

全卷 Data File 工作理想 under ~15 min。Sort → highlight quotable numbers → outline only。Never copy 長段 background。
