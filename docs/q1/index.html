英文 Q1

Discussion paper · Data File · 計時練習

1. Exam role

  • 型式＝internal discussion paper / memo（虛構近香港城市，常見 City of Jade）。
  • Data File＝答題物料，唔係「讀完再寫作文」。
  • 官方大致兩塊：① two major problems + implications；② feasible measures（全文 English）。

2. 開卷 Scratch（2–3 min）

只寫 keywords，唔抄 Data File 長句。

  1. 題目要求一句：寫畀邊個／要咩 recommendation／政府目標。
  2. 關鍵數字／矛盾：3–5 個 quotable；來源標 A–G。
  3. 每條旁標 P1／P2／Rec／Obj — 用唔到就劃走。
  4. Outline：P1／P2 → Options + objection → Recommend（mix／pilot／KPI）。
  5. Criteria 四格：effectiveness｜cost｜stakeholders｜feasibility。
  6. 時間 checkpoint（例）：15′ Data File 完｜40′ 寫到 recommendation｜55′ 收尾 risks。

3. Answer frame Fixed skeleton

Opening → Problem analysis → Option comparison → Recommendation → Close。適用房屋、長者、勞工、環境、交通、醫療等——只換例子同措施。

  1. Opening（1–2 句） — 核心問題 + 政府目標。越短越好；唔堆背景／數字；唔抄公文 Purpose。
  2. Problem analysis（2 個） — 每個：是什麼 + implications（用 Data File 證據）。典型 implications：fiscal／manpower／service quality／public confidence／knock-on effects。Analyse，唔 paraphrase。
  3. Option comparison（2–3 · 得分核心） — 固定 criteria：effectiveness｜cost／resources｜feasibility｜stakeholder impact／acceptance。主動回每 option 嘅最強 objection。
  4. Recommendation — 清晰選項（one 或 mix）。必須：who leads、pilot／phased、KPIs、timeline、resource condition。效果用 may／could／if accompanied by…。
  5. Close（短） — residual risks + 如何 monitor／review。
  • 全卷 Data File 理想 < ~15 min；唔好逐份 document 由頭讀到尾。
  • Never copy 長段 background（paraphrase of background scores nothing）。

4. 句式 starters（topic-agnostic）

考場套骨架；詳細句式見「句式庫」。

StageEnglish starters
OpeningThe main challenge is… / The key issue facing the administration is…
ImplicationsThis may give rise to… / There could be knock-on effects on… / Left unaddressed, the problem risks… / The fiscal implications warrant careful consideration.
ComparisonOption A scores higher on feasibility but lower on cost-effectiveness. / While Option B may deliver quicker results, it carries greater residual risks. / After weighing the trade-offs…
RecommendationIt is recommended that a pilot be launched in… / Implementation should be phased, starting with… / The [Bureau] should lead, with support from… / KPIs should be set to measure…
ConstraintsSubject to available resources… / Contingent on… / In the interim…
CloseResidual risks remain and should be monitored. / A review should be conducted after 12–18 months.

5. Sample outline — Housing waiting list 綜合框架

同一 skeleton；換例子同措施即可套去長者照顧、簡約公屋、門診輪候等。

  1. OpeningThe main challenge is the persistently long waiting time for public housing. The government’s objective is to increase supply while managing fiscal and land constraints.
  2. Problem analysis Problem 1: Insufficient 「熟地」 supply → knock-on effect of delayed construction and rising public dissatisfaction.
    Problem 2: Limited construction capacity and labour shortages → risk of cost overruns and further delays.
  3. Option comparison Option A (accelerate land resumption): higher effectiveness on supply, but lower feasibility due to legal and community resistance.
    Option B (expand modular integrated construction + import labour): more feasible in the short term, but residual risks on quality control and local labour impact.
    Mix preferred after weighing trade-offs.
  4. RecommendationIt is recommended that a pilot of modular construction be launched on already-earmarked Northern Metropolis sites, while accelerating land resumption for the next phase. The Housing Bureau should lead, with the Development Bureau supporting land supply. KPIs: number of units completed and average waiting time reduction after 18 months. Subject to available construction capacity and funding.
  5. CloseResidual risks remain around labour availability and community opposition; these should be monitored through quarterly reviews.

6. Shared frames（Q1／Q2）

兩邊卷都用得着——只換例子同措施。

  • 有助……惟須…… / This helps to… but must be accompanied by…
  • 權衡利弊後…… / After weighing the pros and cons…
  • 短期……惟長遠…… / In the short term… but in the long term…
  • 建議先推行試點…… / It is recommended that a pilot be launched…
  • 視乎可用資源…… / Subject to available resources…
  • 仍有剩餘風險，應持續監察。 / Residual risks remain and should be monitored.
  • 應設定指標以量度成效。 / KPIs should be set to measure effectiveness.

7. Data File 用法

  • Data File＝輔助，唔係答案本——唔背、唔大篇抄；主體係你嘅分析。
  • 流程：先大綱 → 定向翻查 → 整合。訪談＝stakeholder；數字＝一句＋implies／points to…。
  • 冷門／補強／平衡 objection 時多用；每段最多 1 個引用。

8. 公務員語氣

Internal memo——冷靜、可執行；唔係社論或 IELTS。

  • 角色＝內部官員（建議、分析），唔係評論員／NGO。中立＋事實；weighing／hedge；部門＋KPI。
  • 避免：I think、絕對化、「政府明顯失敗」；少用 Unlike／Better than 暗示舊政策做錯；建議唔好只講「加強宣傳」。

9. Conciseness＋字數

  • 每句有功能（問題／implication／比較／objection／recommend）。數字只揀撐論點嘅；引完一句 implies。
  • 時事：DF 優先；外加只借措施樣板（who／pilot／「有助…但須…」）——唔堆新聞入 Opening。
  • 字數：官方無硬性字數——質＞量；唔為填頁灌水。坊間「幾頁／幾多字」唔當指標。

10. 冷門題

  • Data File 就係全部背景——唔熟領域都唔使背史；先 sort／highlight，再跟框架寫。
  • 用固定 criteria 拆；結構仍跟本頁 memo——唔另套四段式。

11. Time budget

全卷 3 hours · both languages。English 理想 under ~1/3，留時間寫中文卷。Q1 坊間常用 ~20′ 大綱／Data File + ~70′ 寫（非官方；以紙上 checkpoint 為準）。

必用 10 句 文筆一般都夠

考試靠骨架，唔靠文采。每段套住 Data File 數字用；下面搜尋有更多。

  1. The key concern is… 核心問題係…
  2. This risks exacerbating / undermining… 恐會加劇／削弱…
  3. There could be knock-on effects on… 或會對…產生連鎖影響
  4. As indicated in Document X… 據文件 X…（一句，唔抄長段）
  5. On balance, Option A is preferable because… 權衡後較宜選 A，因為…
  6. This directly addresses the concern that… 此舉直接回應…嘅疑慮
  7. It is recommended that [dept] … within [timeframe], subject to… 建議由…於…內推行，惟須…
  8. A sequenced / pilot approach would… 分階段／試點有助…
  9. Success should be reviewed against [2–3 KPIs]… 宜以…檢討成效
  10. Residual risk remains… and should be monitored. 殘餘風險為…，須持續監察
—
