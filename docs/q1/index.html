英文 Q1

Discussion paper · Data File · phrase bank

Exam role

  • Paper 型式是 internal discussion paper / memo（虛構近香港城市，常見設定：City of Jade）。
  • Data File 是答題物料，不是一篇要你「讀完再寫作文」的 essay。
  • 官方 sample 大致兩大塊：① 指出 two major problems + implications；② Recommend feasible measures — 全文用 English 起草。

開卷 Scratch paper（2–3 min）

只寫 keywords，唔抄 Data File 長句；之後一路寫一路對。

  1. 題目要求一句：寫畀邊個／要咩 recommendation／政府目標（improve X while containing cost）。
  2. 關鍵數字／矛盾：3–5 個 quotable；來源標 A–G。
  3. 每條資料旁標 P1／P2／Rec／Obj — 用唔到就劃走。
  4. Outline：P1／P2（現象→implication）→ Options A／B／C + objection → Recommend（mix／pilot／KPI／lead）。
  5. Criteria 四格：effectiveness｜cost｜stakeholders｜feasibility。
  6. 時間 checkpoint（例）：15′ Data File 完｜40′ 寫到 recommendation｜55′ 收尾 risks。
  • Objection 要喺比較段主動回，唔好留到最後。
  • 背景長段唔抄 — paraphrase of background scores nothing。

Answer frame（內部討論文件）

Data File 係物料，唔係作文。分析問題 → 影響 → 可行措施（who / when / resources）。

  1. 1. Opening（1–2 sentences） 一句點出問題 + 政府目標（criteria），方便後面 weighing。
    例：問題是 X；目標係 improve Y while containing fiscal / social cost。
    Intro 越短越好：唔好喺開頭堆 Data File 背景或多個實數——數字留畀 analysis／recommendation；分數唔喺華麗公文格式。
  2. 2. Problem analysis 2 main problems + implications（users / fiscal / social）。證據來自 Data File：analyse，唔好 paraphrase。
    每條：現象 → 影響邊啲人／錢／社會 → 點解 urgent。
  3. 3. Option comparison（score core） 比較 2–3 options，用同一套 criteria：effectiveness · cost / resources · stakeholder impact · feasibility / risk。
    主動回應 Data File 入面嘅 objections（唔好裝睇唔到）。
  4. 4. Recommendation 揀 one option 或 mix；說明點解係最好平衡。
    Concrete delivery：phased rollout / pilot / KPIs。
    語氣：可寫 conditional／phased（e.g. proceed on a pilot basis subject to…）——清晰推薦，唔係「利弊各半」；效果用 may／could／if accompanied by…，唔好 will definitely。
  5. 5. Optional close Residual risks / follow-up evaluation（短）。

Data File 用法

  • Data File＝輔助，唔係答案本——唔好大篇抄／背誦；主體係你嘅分析。
  • 流程：先大綱（問題＋每段用途）→ 定向翻查 → 整合。訪談＝stakeholder 角度；數字＝一句佐證＋implies／points to…。
  • 冷門題、補強論據、平衡 objection 時多用；每段最多 1 個引用。

Conciseness（精簡）

  • 每一句要有功能：界定問題、implication、比較、回 objection、或推 recommendation。Every word should move the argument forward.
  • Data File 數字／引述：只揀真正撐論點嘅；引完寫「reflects／implies／points to…」一句。用唔到就 drop（scratch 可 dump 多幾個，正文唔使晒）。
  • 唔好重複鋪陳、堆砌「有分量」句子；政府語氣＝清楚可讀，唔係字數競賽。
  • 時事點用：Data File 優先；外加時事只借措施樣板（who／pilot／「有助…但須…」長遠意義），舉一反三寫 option——唔堆新聞入 Opening；每段最多 1 個實數／措施名。
  • 字數：官方無硬性字數——質＞量；唔好為填頁灌水。Eng 約 70–90 分鐘寫準就得。坊間「幾頁／幾多字」只係觀察，唔當指標。

Hard rules

  • 唔好逐份 document 由頭讀到尾。
  • 全卷 Data File 工作理想 under ~15 min。
  • Never copy 長段 background（官方警告：paraphrase of background scores nothing）。

冷門題

  • Data File 就係全部背景——唔熟領域都唔使背史；先 sort／highlight，再跟框架寫。
  • 用固定 criteria 拆：effectiveness · cost · stakeholders · feasibility／短長遠——唔靠臨場搜尋。
  • 結構仍跟本頁 memo 框架；唔另套四段式。

題型拆解 · 公務員語氣

Internal memo／discussion paper——冷靜、可執行；唔係社論或 IELTS 作文。

  • 段落編排：Opening（問題+目標）→ P1／P2 + implication → Options 比較（含 objection）→ Recommend（who／when／resources／KPI）。一段一事。
  • 政府語氣：weighing（on balance / while recognising）；hedge 風險（may／could）；主動語態寫責任部門；用「the Administration／the Department should…」＋具體措施／KPI。
  • 避免：I think、絕對化、「政府明顯失敗」等評論員句；唔抄 Data File 背景（paraphrase scores nothing）；建議唔好只講「加強宣傳」。

Time budget reminder

全卷 3 hours · both languages。English reading 理想 under ~1/3 of total time，留時間寫中文卷。
