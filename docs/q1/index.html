政策溫習卡（閃卡）→ 政策 tab

Q1 Discussion Paper / Memo：精簡版

考政策分析同取捨，唔係抄背景。每個問題要由資料推到影響，最後提出可執行方案。

  1. 1. Sort the Data File（0 至 5 分鐘）

    先圈出角色、對象、任務目標，再分類：P1/P2＝主要問題及數據；Opt＝方案、成本、時間、效益；Obj/Con＝反對意見及限制；Rec＝可落實措施、試點或 KPI。略過與政策問題無直接關係的資料；唔好逐頁精讀，重點係搵可用證據。

  2. 2. Identify Problems & Implications

    揀出兩個不同、互不重疊的主問題。每個問題按 Problem → Evidence → Implication 寫。唔好只寫表面現象；要用數據說明點樣影響服務使用者、公帑或制度，以及點解需要政府介入。

  3. 3. Compare Options

    用同一套準則比較：Effectiveness（能否處理主要問題）、Fiscal cost（成本是否可持續及符合財政限制）、Feasibility / manpower（人手及時間是否可行）、Acceptance / accessibility（目標人士能否使用）。交代各方案利弊、取捨及選擇理由。反對意見直接在相關方案比較段回應，唔另開獨立反駁段。

  4. 4. Recommend & Close

    提出首選方案並交代 Who（主責及協作機構）、When / Pilot（開始時間及試行地點）、Resources（所需開支及財政限制）、Complementary measures（申請、交通、數碼支援等配套）、KPIs / Review（衡量指標、檢討時間及是否擴展）。最後簡潔重申建議，以合適 memo 語氣收結。

Memory cue： Sort → Problem + impact → Compare → Recommend + delivery

Exam reminder：限時先整理資料同列骨架；唔好將 Data File 背景改寫成文章。

Answer frame

Fixed skeleton，5 段 11 句填表公式

做完 15 至 20 分鐘四步速讀後，最忌一邊寫一邊重新造句。直接用下面 5 段 11 句 Slot-in Assembly 公式，將標記好嘅 keywords 填入句式路軌，55 至 65 分鐘零卡頓寫出 ~700 字高分 Memo。

  • 全卷 Data File 理想 < ~15 min；唔好逐份 document 由頭讀到尾。
  • Never copy 長段 background（paraphrase of background scores nothing）；善用 While [表面數字], [真實缺口]... 做綜合對比。
  1. 1. Opening（固定 2 句，~50 字，3 min）

    核心痛點 + 本文目的與衡量準則（criteria）。越短越好；唔堆背景／唔抄公文 Purpose。

    句 1（痛點）：Against this backdrop (ass-08), [受影響群體 + 1 個核心總數] face acute challenges in [議題].
    句 2（目標＋Criteria）：This paper examines two major bottlenecks in [議題] and recommends feasible measures to [政策目標] while containing fiscal and manpower pressures.

  2. 2. Problem analysis（每題固定 3 句 × 2 段，~220 字，15 min）

    每個問題嚴格跟 「現象 Topic Sentence → Data File 對比數據（While A, B） → 連鎖後果 Knock-on Effect」 三句式。Analyse，唔 paraphrase。

    句 1（現象）：The primary challenge lies in [Problem 1 keyword].（P2 用：Secondly, a key bottleneck is (ass-02) [Problem 2 keyword].）
    句 2（對比證據）：As indicated in Document A, while [表面數字], [真實缺口數字].
    句 3（連鎖後果）：Left unaddressed, the problem may cascade into (imp-04) [社會／用家後果], and there could be knock-on effects on (imp-02) [財政／公院／長遠體系後果].

  3. 3. Option comparison（固定「1 + 2 + 2 + 3 句」結構，~220 字，18 min，得分核心）

    固定 4 準則：effectiveness｜fiscal sustainability｜manpower feasibility｜stakeholder accessibility。極重要：Q1 無獨立反駁段，反對意見喺首選方案段內消化（Addressing Objections Inline）。

    引子（1 句）：Weighing the options against effectiveness, fiscal sustainability, manpower feasibility, and stakeholder accessibility:
    淘汰 Opt 1（2 句）：Option 1 ([名稱]) offers [1 個好處]. That said (dis-04), the fiscal implications warrant careful consideration (imp-05): at [$X M/yr], it breaches the Treasury Branch's [$Y cap] and fails to resolve [核心樽頸].
    淘汰 Opt 2（2 句）：Option 2 ([名稱]) expands long-term capacity. By contrast (dis-07), its [$X B] capital cost, [N-year] lead time, and need for [N staff], where a key bottleneck is (ass-02) the existing [X%] vacancy rate, render it unviable for urgent relief.
    首選 Opt 3＋段內消音（3 句）：From a cost-effectiveness perspective (ass-06), Option 3 ([名稱]) is preferable because it unlocks [閒置資源] within [$X M] and a [N-month] lead time. Critics may note that [Doc C 反對意見]; however, this concern can be directly mitigated by accompanying the scheme with [具體配套措施].

  4. 4. Recommendation（引子 + 4 個 Bullet Points，~180 字，15 min）

    必用 4 個分點寫齊 Who / When & Pilot / Resources / Complementary 四大得分位，慳水慳力又唔漏分。

    引子：On balance (ass-01), we propose a phased approach, beginning with (rec-02) Option 3 reinforced by administrative streamlining:
    Who：[Bureau A] should be designated as the lead department (spc-01), supported by [Dept B] and accredited operators.
    When & Pilot：A targeted pilot should be rolled out in (rec-03) [2 個高需求地區] within [N months], covering [N target users].
    Resources：Non-recurrent expenditure of [$X M] should be sought (spc-07) for [IT/setup], while recurrent costs should be ring-fenced (rec-10) within [$Y M/yr].
    Complementary（前後對比）：Eligibility criteria should be streamlined to (rec-06) replace the [X-page form] with a [2-page fast-track declaration], cutting processing time from [X weeks] to [Y days].

  5. 5. Closing（固定 2 句，~60 字，4 min）

    3 個可量度數字 KPI + 中期檢討時間 + 公務員呈批結語。

    句 1（KPIs）：Progress should be monitored against clear KPIs (mon-01), specifically [KPI 1: 使用率], [KPI 2: 輪候時間由 X 減至 Y], and [KPI 3: 負面指標下降 Z%].
    句 2（Review + 收結）：A mid-term review should be conducted within [6/12] months (mon-02), and consideration may be given to scaling up subject to review findings (rec-08). For Members’ consideration (dis-10).

必用 10 句、句式搜尋／篩選同五段 Shared frames → 句式 tab。

必用 10 句＋搜尋／篩選＋Opening→Closing 五段句式卡（篩選會同步套用）。

文筆一般都夠

考試靠骨架，唔靠文采。每段套住 Data File 數字用；下面各 stage 有更多句式。

  1. The key concern is… 核心問題係…
  2. This risks exacerbating / undermining… 恐會加劇／削弱…
  3. There could be knock-on effects on… 或會對…產生連鎖影響
  4. As indicated in Document X… 據文件 X…（一句，唔抄長段）
  5. On balance, Option A is preferable because… 權衡後較宜選 A，因為…
  6. This directly addresses the concern that… 此舉直接回應…嘅疑慮
  7. It is recommended that [dept] … within [timeframe], subject to… 建議由…於…內推行，惟須…
  8. A sequenced / pilot approach would… 分階段／試點有助…
  9. Success should be reviewed against [2 to 3 KPIs]… 宜以…檢討成效
  10. Residual risk remains… and should be monitored. 殘餘風險為…，須持續監察

Stage：對應下面 Opening→Closing 五段。

兩邊卷都用得着，只換例子同措施。每段：結構提示 → Shared frames → 對應句式。

1. Opening（1 至 2 句）

核心問題 + 政府目標。越短越好；唔堆背景／數字；唔抄公文 Purpose。
Starters：The main challenge is… / The key issue facing the administration is…

Shared frames

  • 本人贊成……的政策目標，惟反對一刀切……，宜先……。 / I support the aim of …, but oppose a one-size-fits-all approach; we should first….

句式

opening

2. Problem analysis（2 個）

每個：是什麼 + implications（用 Data File 證據）。典型 implications：fiscal／manpower／service quality／public confidence／knock-on effects。Analyse，唔 paraphrase。
Starters：This may give rise to… / There could be knock-on effects on… / Left unaddressed, the problem risks…

Shared frames

  • 有助……惟須…… / This helps to… but must be accompanied by…
  • 短期……惟長遠…… / In the short term… but in the long term…
  • 在長遠方案出台前，需有過渡措施。 / A stopgap measure is needed pending a longer-term solution.

句式

implications, assessment

3. Option comparison（2 至 3，得分核心）

固定 criteria：effectiveness｜cost／resources｜feasibility｜stakeholder impact／acceptance。主動回每 option 嘅最強 objection。
Starters：Option A scores higher on feasibility but lower on cost-effectiveness. / After weighing the trade-offs…

Shared frames

  • 權衡利弊後…… / After weighing the pros and cons…
  • 權衡取捨後，宜採用混合方案…… / After weighing the trade-offs, a mix of … is preferred.
  • 反對者或指……會增加成本／行政負擔；惟若不處理……，長遠代價更高，故仍宜……。 / Critics may say … raises costs/admin burden; yet leaving … unaddressed costs more in the long run, so we should still….
  • 若不採納原建議，仍宜以……作為替代，繼續推進……目標。 / If the original proposal is not adopted, … remains a workable alternative to advance….

句式

comparison, balance

4. Recommendation

清晰選項（one 或 mix）。必須：who leads、pilot／phased、KPIs、timeline、resource condition。效果用 may／could／if accompanied by…。
Starters：It is recommended that a pilot be launched in… / The [Bureau] should lead… / Subject to available resources…

Shared frames

  • 建議先推行試點…… / It is recommended that a pilot be launched…
  • 視乎可用資源…… / Subject to available resources…
  • 應由〔政策局／部門〕主導，並由……支援。 / The [bureau/department] should lead, with support from….
  • 應設定指標以量度成效。 / KPIs should be set to measure effectiveness.
  • 可視乎檢討結果考慮擴大推行。 / Consideration may be given to scaling up subject to review findings.

句式

recommend, specificity, monitor

5. Closing（短）

Residual risks + 如何 monitor／review。
Starters：Residual risks remain and should be monitored. / A review should be conducted after 12 to 18 months.

Shared frames

  • 仍有剩餘風險，應持續監察。 / Residual risks remain and should be monitored.
  • 綜上，本人維持……立場；落實時以……為優先，並持續檢討成效。 / In sum, I maintain …; in delivery, prioritise … and keep reviewing outcomes.

句式

discourse，其他

考場操作 tips

1. Exam role

  • 型式＝internal discussion paper / memo（虛構近香港城市，常見 City of Jade）。
  • Data File＝答題物料，唔係「讀完再寫作文」。
  • 官方大致兩塊：① two major problems + implications；② feasible measures（全文 English）。

2. 開卷 Scratch（2 至 3 min）

只寫 keywords，唔抄 Data File 長句。

  1. 題目要求一句：寫畀邊個／要咩 recommendation／政府目標。
  2. 關鍵數字／矛盾：3 至 5 個 quotable；來源由 A 至 G。
  3. 每條旁標 P1／P2／Rec／Obj ， 用唔到就劃走。
  4. Outline：P1／P2 → Options + objection → Recommend（mix／pilot／KPI）。
  5. Criteria 四格：effectiveness｜cost｜stakeholders｜feasibility。
  6. 時間 checkpoint（例）：15′ Data File 完｜40′ 寫到 recommendation｜55′ 收尾 risks。

3. Data File 用法

  • Data File＝輔助，唔係答案本，唔背、唔大篇抄；主體係你嘅分析。
  • 流程：先大綱 → 定向翻查 → 整合。訪談＝stakeholder；數字＝一句＋implies／points to…。
  • 冷門／補強／平衡 objection 時多用；每段最多 1 個引用。

4. 公務員語氣

Internal memo，冷靜、可執行；唔係社論或 IELTS。

  • 角色＝內部官員（建議、分析），唔係評論員／NGO。中立＋事實；weighing／hedge；部門＋KPI。
  • 避免：I think、絕對化、「政府明顯失敗」；少用 Unlike／Better than 暗示舊政策做錯；建議唔好只講「加強宣傳」。

5. Conciseness＋字數

  • 每句有功能（問題／implication／比較／objection／recommend）。數字只揀撐論點嘅；引完一句 implies。
  • 時事：DF 優先；外加只借措施樣板（who／pilot／「有助…但須…」），唔堆新聞入 Opening。
  • 字數：官方無硬性字數，質＞量；唔為填頁灌水。坊間「幾頁／幾多字」唔當指標。

6. 冷門題

  • Data File 就係全部背景，唔熟領域都唔使背史；先 sort／highlight，再跟框架寫。
  • 用固定 criteria 拆；結構仍跟本頁 memo，唔另套四段式。

7. Time budget

全卷 3 hours，both languages。English 理想 under ~1/3，留時間寫中文卷。Q1 坊間常用 ~20′ 大綱／Data File + ~70′ 寫（非官方；以紙上 checkpoint 為準）。

8. 萬用例子 ↔ 措施

跨題可重用配對。DF 有數用 DF；無就借 who／pilot／KPI／gate 樣板，唔堆新聞入 Opening。

  1. 熱島 例：暑熱走廊 A&E 同低樹冠重疊，私人樓晚間室溫難降。
    措施：已劃定走廊先推 shade＋cool-surface pilot，配 means-tested 頂補；KPI＝熱相關 A&E、shade 覆蓋。
    扣題：鎖「熱暴露→健康／公帑」；capital＋短期紓緩一對。
  2. 熱島 例：一次性綠化後維修歸屬不清，樹冠回落。
    措施：合約寫明 maintenance owner＋12 至 18 個月 canopy KPI；先兩走廊再 scale。
    扣題：打可行性／可持續；反對只批資本唔理營運。
  3. 長者 例：院舍輪候長，護老者入院高峰令社區照顧崩潰。
    措施：輪候最長兩區擴 CCS／day-care＋緊急喘息；院舍擴位須配社區照顧；KPI＝評估至首診中位、14 日喘息覆蓋。
    扣題：措施必須「院舍＋社區」一對。
  4. 長者 例：代金券／POS 開支升但空置同再入院無改善。
    措施：撥款掛鈎質素分／空置率／care-breakdown；季度 dashboard。
    扣題：吸納≠成效；要支付／績效門檻。
  5. 房屋 例：公屋輪候高企，熟地／施工力不足拖慢落成。
    措施：已批北都用地 MIC pilot＋下一步收地加速；HB 牽頭、DEB 支援；KPI＝落成單位、18 個月輪候縮短。
    扣題：mix＝短期產能＋中期土地。
  6. 房屋 例：收地宗數達標但就緒用地／入市滯後。
    措施：works 前設 ready-site gate；聯合收地→熟地時間表＋每季追回；按區 take-up／ready-site KPI。
    扣題：由收地數字轉交付缺口。
  7. 醫療 例：專科門診輪候長，穩定慢性個案佔用專科名額。
    措施：HB／HA 公布專科輪候目標＋穩定個案基層分流 KPI；先兩專科／兩聯網 pilot。
    扣題：who＋specialty-level KPI，唔空喊加強基層。
  8. 醫療 例：學校／NGO 轉介後中度個案久等首診，高危上 HA 亦慢。
    措施：分區試點縮短轉介→首診中位；高危 14 日達 HA；POS 對 outcomes／DNA rate。
    扣題：implications 寫延誤→惡化；鎖 referral pathway。
  9. 環保 例：MSW 回收率僅溫和上升，廚餘廠使用不足，樽頸在收集／源頭分類。
    措施：EEB 牽頭有時限收集＋盤查 surge；建廠資本僅在 utilisation gate 達標後釋放；分區回收／覆蓋／使用率 KPI。
    扣題：產能短缺 vs 收集樽頸；未達標唔先加資本。
  10. 創科 例：資助吸納高但場景驗證／留任／商業化薄。
    措施：下期撥款掛鈎 verified validation＋retention；按企業規模公布吸納／留任 KPI；共用設施／IP 先於再加 MOU。
    扣題：打 soft-money；milestone＋共用能力。
  11. 中小企 例：資助批出多但 12 個月仍使用率低、網絡風險升。
    措施：目錄／POS 加出席同 still-in-use KPI；微企名額圈定；B2G e-invoicing 只作後段 pilot。
    扣題：成效＝持續使用／保安，唔係批核宗數。
  12. 口岸 例：節日高峰臨時候命，P90 飆、疏導遲、無公開暢順 KPI。
    措施：standing SOP（預報／P50 觸發）＋現場授權＋預留疏導；公布 P50/P90、疏導準點、72h brief；有上限 envelope。
    扣題：臨機 vs 制度化；對住 KPI 同控經常開支。
