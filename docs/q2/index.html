考咩

考議題思維，唔係閱讀速度。物料通常 sparse。要：清晰立場 + 理據 + 措施／替代。

官方 sample shape（大牌檔型）

  1. 1. 利弊分析正反
  2. 2. 立場明確支持或反對（唔好兩邊擺）
  3. 3. 跟進支持 → 措施確保目標可達；反對 → 替代方法繼續推目標

固定答題框架

  1. 開首背景一句 + 明確立場
  2. 主體2 個主要理據（各附香港例子／數字）
  3. 反駁回應最強反方 → 為何己方仍較可取
  4. 建議／替代phased／pilot／KPI，唔好空喊加資源
  5. 短結重申立場 + 一句可交付結果

Timed target：約 70–80 分鐘／篇（留時間畀英文卷）。

常見扣分

失敗點解
立場不清／兩邊擺睇唔到 recommendation
空泛、無香港例子唔熟本地政策
無視最強反方分析唔完整
「大幅加資源」無 delivery要 phased / pilot / KPI
