答題框架 · Q2 中文

考議題思維＋書面表達（物料通常 sparse）。考官要：清晰立場、具體理據、可執行建議。考期 2026-12-05。來源：06-Chinese-Drills＋官方大牌檔 shape；EO Classroom 等只作補充，唔跟坊間字數／舊考期／另套四段式。

1 · 官方 shape（大牌檔）

  1. 利弊——正反各點到即止
  2. 立場——明確支持或反對（唔好兩邊擺）
  3. 跟進——贊成＝措施確保目標可達；反對＝替代方案繼續推目標

2 · 五步答題（考場跟呢條）

  1. 開首 2–3 行：目的一句＋明確立場——唔好長 Purpose／背景；開頭唔堆實數
  2. 主體：2 個理據，各附 1 個香港例子／數字／措施名
  3. 反駁：最強反方 → 點解仍揀己方
  4. 建議／替代：pilot／分階段／KPI；唔好空喊加資源
  5. 短結：重申立場＋一句可交付結果

開首立場 → 2 理據（HK）→ 反駁 → 建議 → 短結

時間（非官方參考）：約 10′ 大綱＋其餘寫作；總目標 ~70–80 分鐘（留時間畀英文卷）。Checkpoint：10′ 大綱齊 → 55′ 開始短結 → 65′ 檢查開首立場。

3 · 開卷 scratch（keywords only）

  1. 立場一句（贊成／反對／有條件——唔好利弊各半）
  2. 事實 dump：2–3 個數／年份、主責局署、一項措施（冇把握唔估；局署要對）
  3. 利 2／弊 2 → 正文先揀用
  4. 理據 A／B 各配 1 個 HK 例子
  5. 最強反方＋仍揀己方一句
  6. 建議 2–3（要有 delivery）＋短結關鍵詞

4 · 如何揀立場

無標準立場——要有理據、風險回應、可執行建議。

  1. 先拆題：政策目標？利／險？反方攻邊？要配套／替代？
  2. 三種都得：贊成／反對／有條件贊成——一句釘死。有條件＝肯定目標＋承認風險＋試點／監管
  3. 反對要有貢獻：問題＋更有效／更具成本效益嘅替代
  4. 用政策目標揀，唔用喜好；少寫「一定／必定」→「若配合…有望…」

例：同意推行，惟以分階段試行及完善監管為前提。／不宜即時大規模推行；宜先改善現有服務並做需求評估。

5 · 簡潔 · 字數 · 時間

官方無字數上下限。高分靠每句有功能；灌水失焦＝減分訊號。4–5 頁／千字級只係坊間經驗，唔當硬指標。

  1. 一句一工／一段一職——重述前文填篇幅就刪
  2. 正文每理據只揀 1 個數／措施名；scratch 可 dump 2–3；引完寫「反映／意味住」
  3. 自檢：呢段點樣支持立場？答唔到就改
  4. 少空話：刪「毫無疑問／顯而易見」；寫準＞寫多

6 · 公務員語氣

角色＝潛在政策撰稿人／官員：建議同分析，唔係時評、NGO 或政黨。Tone＝中立邏輯＋有條理建議——唔抄 Purpose／Background 格式。

  • 用公眾利益／可行性／持份者平衡；公文詞：宜、應、可考慮、試點、檢討成效
  • 一段一意；建議段用「一、二、三」方便掃讀
  • 利弊可以寫，但唔好黨派式「之前做錯／不如外國」——改「須兼顧…／宜配套…」
  • 承認複雜但立場前後一致：「有助…但須…」
  • 讀新聞／政策卡三問：成因 → 邊群受影響 → 當局回應是否成比例

7 · 時事用法 · 冷門題

事實庫＝政策 tab。考場唔靠搜尋——靠五步＋百搭角度。唔熟題目都唔使背歷史。

  1. 措施 → 意義：計劃名之後跟長期影響／可優化空間
  2. 舉一反三：相近風險群體／政策樣板類推
  3. 冷門百搭：持份者利弊、短／長遠、成本效益、公平、行政可行性
  4. 冇把握嘅數唔估——寫措施方向／試點／需求評估都好過造假

8 · 練習節奏 · 領域

  1. First drill＝官方「大牌檔」sample
  2. 每週 1–2 題，同一五步；計時 70–80 分鐘
  3. 考前 1–2 月：施政方向＋政策卡；考前 1–2 週：複習框架／語氣／有範文題

每個領域準備：支持 ×2、反對 ×2、建議／替代 ×1–2。
