答題框架 · Q2 中文

來源：06-Chinese-Drills/Q2-Chinese-prep.md。考議題思維，唔係閱讀速度；物料通常 sparse。要：清晰立場 + 理據 + 措施／替代。

官方 sample shape（大牌檔型）

  1. 1. 利弊分析正反（pros / cons）
  2. 2. 立場明確支持或反對（唔好兩邊擺）
  3. 3. 跟進支持 → 措施確保目標可達；反對 → 替代方法繼續推目標（如「美食天堂」）

固定答題框架

  1. 開首2–3 行：目的一句 + 明確立場——唔好長 Purpose／背景，開頭唔堆實數（數字留畀理據段）
  2. 主體2 個主要理據（各附香港例子／數字）
  3. 反駁回應最強反方 → 為何己方仍較可取
  4. 建議／替代phased／pilot／KPI，唔好空喊加資源
  5. 短結重申立場 + 一句可交付結果

開首立場 → 2 理據（HK）→ 反駁 → 建議 → 短結

Timed target：約 70–80 分鐘／篇（留時間畀英文卷）。

參考 EO Classroom：Introduction 佔分極少；分數喺分析＋建議。短而有方向＞模仿公文長開場。Government tone＝邏輯同可讀，唔係照抄 Purpose／Introduction 格式。

開卷 草稿紙（2–5 分鐘）

只寫 keywords，唔抄長句。事實 dump 同結構分開寫，再套五步框架。

  1. 立場一句支持／反對／有條件贊成（唔好利弊各半）
  2. 事實 dump2–3 個實數或年份、主責局／署、最近一項具體措施（冇把握寧願寫「近年／當局正推進」，唔好估錯；局署要對：如勞工處 vs 金管局）
  3. 利 2／弊 2各 capped 兩點半句——正文先揀用
  4. 理據 A／B各配一個 HK 例子／數字／政策名
  5. 最強反方一句 + 點解仍揀己方
  6. 建議 2–3要有 delivery（pilot／KPI／分階段），唔好淨係「加資源」
  7. 短結關鍵詞重申立場嗰句

時間 checkpoint：10′ 大綱齊 → 55′ 開始短結 → 65′ 檢查開首立場一句

練習節奏

  1. First drill＝官方「大牌檔」sample（跟上面框架寫一版）
  2. 之後每週 1–2 個時事議題，同一格式；計時 70–80 分鐘
  3. 考前 1–2 月：熟施政報告／最新政策方向（政策 tab）
  4. 考前 1–2 週：複習高分結構＋政府語氣；題庫有範文先重讀

參考 EO Classroom 資源清單：寫作練結構；事實同語氣用政策卡／新聞稿，唔好另砌資源庫。

題型拆解 · 公務員語氣

Q2 考議題思維＋書面表達：考官睇公務員角度，唔係個人感嘆文。結構同語氣夾錯，即使有料都會失分。

題型拆解（中文卷）

  1. 利弊各點到即止（2 點左右）— 顯示你睇到兩面
  2. 立場一句釘死（支持／反對／有條件）— 唔好「視乎情況」
  3. 理據2 段，每段一理據＋香港例子／政策名
  4. 反駁最強反方 → 點解仍揀己方
  5. 建議贊成＝可執行措施；反對＝替代方案仍推政策目標；要有監察／KPI

段落編排

  1. 一段一意；開首句＝該段主題（topic sentence）
  2. 連接：首先／其次／然而／因此／總括而言 — 少用口語轉折
  3. 建議段用「一、二、三」或分點，方便考官掃讀

句式與語氣（政府角度）

  • 用公眾利益／可行性／持份者平衡，少用「我覺得好慘／好嬲」
  • 措辭偏公文：宜、應、可考慮、分階段、試點、檢討成效
  • 避免口號同空喊「大幅增加資源」；寫邊個局署、邊個 KPI、邊個時間表
  • 對反方要礼貌但堅定：「有意見認為……惟……」

註：坊間「字數／可選語言／資料分析另卷」等聲稱唔當官方標準；答法跟本頁框架同官方大牌檔 shape。

如何揀立場

參考 EO Classroom 等備考思路；無標準立場——重點係有冇足夠理據、風險回應同可執行建議。官方例題（大牌檔）要你：利弊 → 支持或反對 → 贊成措施／反對替代。

  1. 先拆題（2–3 分鐘）：政策目標係咩？建議本身利／險？反方會攻邊點？有冇要求配套／替代／檢討？
  2. 三種都得：贊成／反對／有條件贊成——必須一句釘死。對多數人「有條件贊成」最好寫滿（肯定目標＋承認執行風險＋分階段／試點／監管）。
  3. 反對要有貢獻：唔係淨否決；講現方案問題＋更有效／更具成本效益／更顧持份者嘅替代。
  4. 用政策目標揀，唔用個人喜好：能否解決問題？執行可否改善？邊個受惠／承擔？資源權限夠唔夠？失敗代價？
  5. 唔好把「可能」當「必然」：少寫「一定／必定」；改「若配合……有望……」，顯示成效靠配套。

例：同意推行，但以分階段試行、審慎選址及完善監管為前提。／不應即時大規模推行；宜先改善現有服務並做地區需求評估。

時事素材用法

參考 EO Classroom：高分靠用得準，唔係堆新聞。事實嚟自政策 tab／scratch；正文跟 Conciseness（每理據 1 個數／措施）。

  1. 措施 → 意義：寫完政策名／計劃，跟一句長期影響或可優化空間（例如減碳之餘要補充電覆蓋）
  2. 舉一反三：院舍通風經驗 → 托兒／特殊學校；一項措施可推去相近風險群體
  3. 成效一句：有把握先寫「惠及／達標」數字；冇就寫措施名＋方向，唔估假數
  4. 唔背主題清單：房屋／創科／教育／安老跟政策卡；呢度只練「點樣寫入理據」

簡潔 · Conciseness

參考 EO Classroom：高分唔靠長，而係每句有功能。Marker 時間緊——立場、框架、論證要一眼睇到。

  1. 一句一工：交代問題／指出影響／比較利弊／支撐建議——否則刪或併
  2. 例子為論點服務：scratch 可 dump 2–3 個數；正文只揀 1 個真正撐理據嘅數／措施名，引完寫「反映／意味住」——否則寧願唔引
  3. 一段一職：開首立場／理據A／理據B／反駁／建議／短結——唔好重述前文填篇幅
  4. 自檢：呢段點樣支持我嘅立場？答唔到就改
  5. 政府語氣＝可讀：清楚、有效、少冗句；尊重考官同「公眾時間」

Every word should move your argument forward. 練習目標係判斷力：知咩值得留、咩只係噪音。

字數迷思

參考 EO Classroom：官方無明文字數上限。考官睇清晰立場、結構、分析——唔係頁數。考期跟 2026-12-05（唔跟坊間舊日期）。

  1. 重質不重量：灌水三千字但失焦＝減分訊號；短而準勝過長而空
  2. 時間先於字數：Q2 目標仍約 70–80 分鐘；寫準＞寫多
  3. 經驗範圍（非標準）：有考生話約 4–5 頁／千字級已夠——當參考，唔當硬指標
  4. 避陷阱：平日累積理據／反方；限時練後查結構力度，唔靠臨場灌水
